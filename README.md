# Hospital Beds Management – Microsoft Fabric Analytics Project

## 📊 Overview
This project analyzes hospital operations using Microsoft Fabric**, including:
- Patient admissions
- Weekly service demand
- Staff presence patterns
- Service-level satisfaction and morale
- Critical weeks (e.g., flu outbreaks)


## 🧪 Analytical Queries Included
1. **Busiest Services -  which services handled the most patients  
2. **Staff Load by Week - analyze staff presence patterns  
3. **Critical Event Weeks - identify weeks with overload or flu events
